# Franske ord

Et enkelt og tilgjengelig ordspill for å friske opp fransk. Spillet kan kjøres direkte som en statisk nettside på GitHub Pages.

## Funksjoner

- elleve ordkategorier
- gjennomgang av ord, ett om gangen
- quizer med ti ord
- feilbesvarte ord kommer tilbake på slutten av runden
- resultatet viser riktige svar på første forsøk og hvilke ord som måtte gjentas
- lokal progresjon som gradvis går fra gjenkjenning til skriving
- justerbar skriftstørrelse og støtte for nettleserzoom

## Filer

- `index.html` – grunnstrukturen
- `style.css` – utforming og tilgjengelighet
- `script.js` – spill- og progresjonslogikk
- `vocabulary.js` – kategorier og ordforråd

Åpne `index.html` i en nettleser for å prøve spillet lokalt.
